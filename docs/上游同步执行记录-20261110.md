### 4.1 本机交叉编译踩的坑（可复现）

1. `cargo check -p ksud` 在 Windows 上会因 `userspace/ksud/build.rs` 的 AArch64 bootstrap 汇编失败（无 `clang`/`aarch64-linux-gnu-gcc`/`llvm-mc`）。解法：设 `ANDROID_NDK_HOME`，`build.rs` 会用 NDK clang 汇编。
2. `bindgen` 在 Windows 上找不到 `linux/ioctl.h`（内核 UAPI 头）。解法：把 NDK sysroot 加进 `CPATH` / `CPLUS_INCLUDE_PATH`：
   ```powershell
   $env:CPATH="$ndk\toolchains\llvm\prebuilt\windows-x86_64\sysroot\usr\include;$ndk\toolchains\llvm\prebuilt\windows-x86_64\sysroot\usr\include\aarch64-linux-android"
   ```
3. `bindings.rs` 会在 `OUT_DIR` 缓存，改了 `uapi/*.h` 必须删缓存重生成：
   ```powershell
   Get-ChildItem target\<triple> -Recurse -Filter bindings.rs | Remove-Item -Force
   ```
   否则会报 `cannot find value EVENT_SERVICES in module ksu_uapi`（本轮实际踩到）。
4. Gradle wrapper 下载 `gradle-9.7.1-bin.zip` 直连 `services.gradle.org` 10s 超时。用腾讯镜像下载后放进 `~/.gradle/wrapper/dists/gradle-9.7.1-bin/<hash>/`：
   ```
   curl -L -o gradle-9.7.1-bin.zip https://mirrors.cloud.tencent.com/gradle/gradle-9.7.1-bin.zip
   ```
