features:
  - title: Kernel-based
    details: ShizuSU bekerja dalam mode Linux kernel, dan mempunyai kelebihan diatas aplikasi userspace.
  - title: Kontrol akses daftar putih
    details: Hanya aplikasi yang diberikan izin root yang bisa mengakses `su`, aplikasi lain tidak bisa mengakses su.
  - title: Sistem modul Magic Mount
    details: Dibangun di atas Magic Mount (5ec1cff) yang diwarisi dari SukiSU-Ultra, pemasangan modul langsung berfungsi dan modul Magisk kompatibel langsung.
  - title: Sumber terbuka
    details: ShizuSU adalah projek sumber terbuka dibawah lisensi GPL-3.
  - title: Dukungan kernel lama Non-GKI
    details: Mengembalikan dukungan untuk perangkat Non-GKI / GKI 1.0, mencakup kernel 4.x - 5.4 LTS (3.x eksperimental), menghadirkan root level kernel ke perangkat lama.
  - title: Berbasis SukiSU-Ultra
    details: Fork generasi kedua dari proyek komunitas yang matang, mewarisi dukungan Non-GKI, Magic Mount, KPM, dan lainnya.
  - title: Modul kernel KPM
    details: Dukungan penuh KernelPatch Module (KPM) untuk modifikasi dan penguatan kernel tingkat lanjut.
  - title: Kustomisasi luas
    details: Latar belakang kustom, kelola fitur susfs langsung, sesuaikan DPI, dan desain sesuai keinginan Anda.
